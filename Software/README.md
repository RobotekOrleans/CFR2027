#  Software — CFR2027

This directory contains the robot's software:
* The **ESP32 WROOM32** code, controlling the drivetrain and handling sensor data acquisition.
* The **Raspberry Pi 4** code, managing robot localization in the arena and controlling actuators.

---

## ESP32 Code Architecture

The software relies on **FreeRTOS** and utilizes both cores of the ESP32 to ensure real-time execution:

* **Core 0 — `ThreadComRasbe`:**
  * **UART Communication:** Receiving and parsing commands from the Raspberry Pi (`readSerialData()`, `parseData()`).
  * **Ultrasonic Sensors:** Managing 4 sensors via interrupts (`IRAM_ATTR echoInterrupt()`, `declencherPing()`, `traiterUltrason()`).
  * **Safety Watchdog:** Emergency stop if no communication is received for 500 ms (`verifierWatchdog()`).
  * **Telemetry:** Sending sensor distance values to the Raspberry Pi every 100 ms (`envoyerTelemetrieUS()`).

* **Core 1 — `ThreadDeplacement`:**
  * **Motor Control:** Generating PWM and direction signals for motor drivers.
  * **Feedback Control:** Trajectory and motion control algorithms.

* Inter-Core Communication
    **Core 1** receives instructions from **Core 0** via a FreeRTOS message queue (`xQueue`). This mechanism allows updating motor speed setpoints or triggering an immediate emergency stop if an obstacle is detected by an ultrasonic sensor.

## Communication Protocol (UART)

Messages exchanged between the Raspberry Pi and the ESP32 use text frames enclosed in `<...>`:

### Raspberry Pi ➔ ESP32 (Received Commands)

* **Motor Commands:** `<V,X0,X1,X2,X3>` (parsed by `parseData()`)
  * Speed setpoints for each motor.
  * `X0` = Front-Left, `X1` = Front-Right, `X2` = Back-Left, `X3` = Back-Right.

* **Ultrasonic Sensor Mask:** `<I,i0,i1,i2,i3>` (parsed by `parseData()`)
  * Enables/disables obstacle alerts for specific sensors (`0` or `1`).
  * Sensors: `i0` = Front, `i1` = Right, `i2` = Left, `i3` = Back.


### ESP32 ➔ Raspberry Pi (Sent Data)

* **Ultrasonic Telemetry:** `<US,i0,i1,i2,i3>` (generated by `envoyerTelemetrieUS()`)
  * Periodic transmission of measured distances in centimeters.
  * Sensors: `i0` = Front, `i1` = Right, `i2` = Left, `i3` = Rear.

## Building

### Prerequisites
* [Visual Studio Code](https://code.visualstudio.com/) with the **PlatformIO IDE** extension.

### Instructions
1. Open the **`Software`** folder in VS Code.
2. PlatformIO automatically detects `platformio.ini` and downloads the toolchain.
3. **Build:** Keyboard shortcut `Ctrl + Alt + B`.
4. **Flash to ESP32:** Keyboard shortcut `Ctrl + Alt + U`.
