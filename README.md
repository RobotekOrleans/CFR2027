# French Robotics Cup — Robotek Orléans



## About



This project was initiated by Robotek Orléans to design and build an autonomous robot for the French Robotics Cup (Coupe de France de Robotique), organized under the Eurobot framework.



The goal of the competition is to build a fully autonomous robot capable of performing specific tasks defined in the official rules. The organizers grant complete freedom regarding the robot's structure, mechanical design, and actuation systems. The primary requirement is to successfully pass the homologation phase by adhering strictly to the official competition regulations.

## Repository Structure



The project files are structured as follows:



- regulation-file/ — Rules, documentation, and resources provided by the Eurobot / French Robotics Cup organizers.

- project-management/ — Project tracking, planning, risk analysis, and management resources.

- software/ — Embedded source code, control algorithms, software architecture, and setup guides.

- hardware/ — CAD models, 3D printing files, PCB designs, and electrical schematics.
